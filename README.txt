Ganpati Aagman Competition Website
=================================

Open index.html to start.

Pages:
- index.html: Home
- registration.html: Registration
- upload.html: Dynamic photo/video upload
- success.html: Confirmation

This version is a fully working front-end demo using localStorage so you can test the complete flow without credentials.

For production:
- Connect registration data to Supabase PostgreSQL.
- Upload media to Supabase Storage.
- Add Supabase Row Level Security and secure upload policies.
- Never expose the Supabase service-role key in browser code.

The supplied project specification is reflected in the page flow and fields.
